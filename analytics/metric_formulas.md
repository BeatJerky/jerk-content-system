# Metric Formulas

## Follower Conversion Rate
```
Follows Gained ÷ Reach × 100
```

## Save Rate
```
Saves ÷ Reach × 100
```

## Share Rate
```
Shares ÷ Reach × 100
```

## Comment Rate
```
Comments ÷ Reach × 100
```

## Average Watch Time
Use platform analytics to measure by post.

## Audience Conversion
Track which content led to:
- profile visits
- follows
- message DMs
- event sign-ups
- volunteer interest
