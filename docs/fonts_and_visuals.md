# Fonts and Visual System

## Recommended Font Structure
- Hook titles: Anton or Bebas Neue
- Captions: Montserrat
- Scripture emphasis: Playfair or Cinzel

## Visual Rules
- Use a minimum 20–30px text size for mobile
- Keep text in the center-upper third of the frame
- Avoid bottom 20% and right 15% due to platform UI
- Keep line length short and readable
- Limit to 2 fonts per video
- Use strong contrast (white text with black outline is a safe default)
- Always preview on a phone before publishing

## Common Visual Mistakes
- tiny text on mobile
- too many decorative fonts
- dark text on dark backgrounds
- long passages in all caps
- cluttered composition
- over-designed “gospel flyer” aesthetic

## Practical Rule
Clean and bold beats busy and cluttered.
